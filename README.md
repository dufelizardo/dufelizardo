Senior Quality Engineer with extensive experience in Software Quality Engineering, test automation, and automation architecture for complex systems. Currently leading test automation initiatives for a critical Capital Markets platform at **GFT Group**, with Python, Robot Framework and Playwright, CI/CD, test strategy, and end-to-end requirements traceability (Jira/Xray/Confluence).

## Featured projects

### [LKDF — Layered Keyword-Driven Framework](https://github.com/dufelizardo/Layered-Keyword-Driven-Framework-LKDF)
Reference architecture for test automation that combines Clean Architecture with Page Object Model, Keyword-Driven and Data-Driven testing. Four decoupled layers (Test → Scenario → Flow → POM) with a strict downward dependency rule, keeping large suites maintainable as they grow.

### [AQuA-QE Enterprise Blueprint](https://github.com/dufelizardo/aqua_qe_lkdf)
Research initiative on modern Quality Engineering, traceability, AI-assisted testing, and knowledge-driven validation, built on the LKDF approach — Robot Framework, Python, REST APIs, RAG, and LLM workflows.

### [Mais Saúde Pública](https://github.com/dufelizardo/mais_saude_publica)
Public health network management platform: Spring Boot, Angular, and PostgreSQL, with JWT authentication and a branch promotion pipeline gated by JUnit, CodeQL, and an LKDF-based Robot Framework acceptance suite. Runs on a home-lab Kubernetes (K3s) cluster with GitOps via Argo CD.
[**→ Navigate the prototype**](https://dufelizardo.github.io/mais_saude_publica/)
